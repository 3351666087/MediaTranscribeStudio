## 1. 问题与方法

本轮不从现有生产流水线反推测试，而先把最终目标拆成五个可观察问题：

1. 媒体中是否存在可转录的词汇语音，而不是只有静音、环境声或非词汇人声。
2. 有多少说话人，以及每个带时间的片段可由哪些声学身份解释。
3. 每段说了什么、使用什么语言，是否包含同人或多人代码切换。
4. 本地 LLM 能否在不知道真值时利用 VAD、diarization 和两个 ASR 的独立证据改善最终结果。
5. 同一次语义调用生成的中文翻译是否完整且确实为目标语言。

批次先冻结 20 个短样本及盲身份，再分别冻结 Qwen3-ASR-1.7B、Whisper large-v3-turbo、FunASR FSMN-VAD 和 Pyannote Community-1 输出。四份输出完成后才打开密封真值，并由独立审计器评分。LLM 提示没有访问密封真值，所有输入均以 SHA-256 绑定。

20 例包括 7 个静音/环境声/非词汇人声，9 个代码切换样本，1 个真实 AISHELL-4 五人普通话会议，1 个真实 VoxConverse 两人会话，1 个派生八人压力样本和 1 个真实单人英语样本。它能暴露架构错误，但仍不是互斥 held-out，也远小于发布矩阵，因此不能证明“任意人数”或“任意语言”。

## 4. v1、v2、v3 失败链

### v1：自由生成完整时间轴

模型可以自行输出文本、角色和起止时间。它把一整段普通话逐字稿绑定到 `0.031-1.162 秒` 的单段并只保留一名主要说话人，虽然同时宣称共有两人。失败原因不是 JSON 格式，而是让语言模型承担了它没有声学证据支持的连续时间估计和身份重建。

### v2：索引绑定但候选不局部约束

改为引用 Whisper segment index 后，时间不再自由生成；但提示仍暴露全局说话人集合。模型在第 9 段选择了与该时间段不重叠的身份，确定性校验正确拒绝。失败说明“只能引用已知 ID”仍不够，每个决策必须只看到与该局部时间重叠的声学候选。

### v3：局部声学候选与确定性补齐

每个 Whisper 段附带局部 `acousticCandidates`，host 校验索引恰好覆盖并在确定性约束允许时修正。该版本完成 `19/20`，总墙钟 `1914.867406 秒`、生成 `6697 tokens`。一个 `4079-token` prompt 在 `4096` context 下只剩 17 个生成 token，切到 `8192` 后才完成。VoxConverse 长例即使使用 `8192`，仍在 `4725` prompt tokens 后生成满 `900` tokens 并以 `doneReason=length` 截断。

v3 证明局部约束能提高结构完成率，却没有证明自由生成最终全文能提高质量。其平均最终文本仍显著差于逐例 best base，并且人数与语言决策继续退化。因此该工具永久保持诊断用途，不进入生产调用链。

## 5. 对生产架构的复盘

人处理大批量样本时，并不会重新“听写”所有声学细节：先判断有无词汇语音，再比较多个独立时间轴和文本候选；只在局部冲突处结合相邻上下文、问答关系、语法和语言一致性做选择；最后检查译文是否覆盖全部选中文本。可落地架构应复制这个决策结构，而不是让 LLM 生成一个看似完整但无法追溯的新答案。

生产推荐路径：

```text
媒体探测/规范化
  -> VAD + 非词汇声学候选
  -> 多个完整 diarization/timeline 候选
  -> canonical speaker 映射与 Dynamic-N 约束
  -> 开放集 LID/und + 多 ASR/N-best 候选
  -> 哈希绑定的五域 candidate lattice
  -> 全局 speech/timeline 优先裁决
  -> 逐段 speaker + language + ASR 原子裁决
  -> 同次生成绑定所选 ASR 的翻译
  -> host 确定性 composition 与翻译后验门禁
  -> 统一后语义评分、人工复核和交付
```

本轮生产代码落实了以下约束：

- LLM 只返回按位置排列的候选索引，不能创建时间、身份、语言或 ASR 候选。
- 媒体级结构先决定；逐段 speaker/language/ASR 三域不可拆开裁决。
- 目标段只带前后各两段上下文；全局结构最多均匀采样八段，不再把全文重复塞进每批。
- 默认批大小保持 8，避免 32 组大输出导致截断。
- 翻译在同次语义调用生成，并绑定 segment、所选 ASR candidate、source text SHA 和目标语言。
- 翻译必须保留数字、版本、URL、API、PayPal 等受保护字面量；普通正文的目标文字系统不足 50% 时拒绝并重试或 fail closed。
- schema、候选资格、哈希、人工锁或跨域一致性任一不成立都拒绝，不以 LLM 的自然语言自信度覆盖声学证据。

## 6. 下一轮实验

下一轮不继续调这 20 例的 prompt。应先补候选上限和新的隔离样本，再用完全相同的终态指标验证：

1. 加入 MOSS/Community-1/Pyannote/NeMo 的独立完整 timeline 候选，特别针对 N=3/5/8、重叠和快速轮换。
2. 加入 open-set LID 与明确 `und` 候选，避免模型只能在错误语言集合里强选。
3. ASR 使用 Qwen3-ASR、Whisper、旗舰长尾模型与原生 N-best，LLM 仅作局部选择及证据支持的最小修复。
4. 把长窗口拆成局部语义块，保持相邻上下文和跨块 speaker/术语状态；翻译与裁决同次完成，但按块输出并由 host 对账完整性。
5. 新建按 dataset/recording/speaker 隔离、从未用于本轮开发的 held-out，逐桶报告最终人数、DER/JER、cp/tcp/SA-WER/CER、LID/切换、overlap、幻觉/删除、翻译完整性、复核量、RTF 和峰值资源。

只有新的 held-out 在所有硬域通过统一门禁，才可提升对应语言、人数和场景的发布声明；有限分桶不得外推为无限人数或全球所有语言。
